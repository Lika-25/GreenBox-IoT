# Розумна тепличка (Фітобокс) - Проєкт IoT

Цей проєкт є веб-додатком для моніторингу та управління параметрами розумної теплиці. Розроблено в рамках лабораторних робіт з дисципліни «Проєктування та моделювання IoT-систем».

## 🏗️ Архітектура рішення
Система побудована за архітектурою **MTV (Model-Template-View)** на базі фреймворку Django.
Серверна частина розгорнута за допомогою класичного стеку:
*   **Django** — бізнес-логіка.
*   **uWSGI** — WSGI-сервер для взаємодії з Python.
*   **Supervisor** — менеджер процесів для підтримки роботи uWSGI у фоні.
*   **Nginx** — веб-сервер (reverse proxy), що приймає запити на порту 9000.

*(Тут можна додати картинку схеми, якщо є)*

## 👥 Розподіл ролей у команді
*   **Анжеліка** — базовий каркас проєкту, налаштування серверної частини (uWSGI, Nginx, Supervisor), загальний інтерфейс та моделі.
*   **Микола** — розробка модуля датчиків (sensors).
*   **Ірина** — розробка модуля аналітики (analytics).
*   **Роман** — розробка модуля безпеки (security).

## ⚙️ Керівництво програміста (Як запустити)
Оскільки для роботи uWSGI та Nginx необхідне Linux-середовище, проєкт запускався через WSL (Ubuntu).

**Крок 1. Клонування репозиторію:**
\`\`\`bash
git clone [https://github.com/Lika-25/GreenBox.git](https://github.com/Lika-25/GreenBox-IoT.git)
cd GreenBox
\`\`\`

**Крок 2. Створення віртуального середовища та встановлення залежностей:**
\`\`\`bash
python3 -m venv env
source env/bin/activate
pip install -r requirements.txt
\`\`\`

**Крок 3. Міграції бази даних:**
\`\`\`bash
python manage.py migrate
\`\`\`

**Крок 4. Запуск через Supervisor та Nginx:**
\`\`\`bash
# Запуск сервера додатку
sudo supervisorctl start greenbox
# Запуск веб-сервера
sudo service nginx start
\`\`\`

Додаток буде доступний за адресою: `http://localhost:9000/`
