# Розумна тепличка (Фітобокс) - Проєкт IoT

Цей проєкт є комплексним веб-додатком для моніторингу, аналізу та управління параметрами розумної теплиці. Розроблено в рамках дисципліни «Проєктування та моделювання IoT-систем» командою студентів групи КНТ-216м.

## 🏗️ Архітектура рішення
Система побудована за архітектурою MTV (Model-Template-View) на базі фреймворку Django. 
Серверна частина розгорнута за допомогою production-стеку: Django, uWSGI, Supervisor, Nginx. База даних — SQLite3.
